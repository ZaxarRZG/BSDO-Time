Для получения актуальной даты и времени в JavaScript используется встроенный объект **`Date`**. При создании нового экземпляра этого объекта без аргументов он автоматически инициализируется текущим моментом времени согласно системным часам пользователя.

Вот основные способы работы с ним:

### 1. Получение объекта даты
Самый простой способ — создать новый объект:
```javascript
const now = new Date();
console.log(now); 
// Вывод: Fri Oct 27 10:30:45 2023 GMT+0300 (часовой пояс зависит от системы)
```

### 2. Получение отдельных компонентов
Вы можете извлечь конкретные части даты и времени с помощью методов геттеров. Обратите внимание, что **месяцы в JS начинаются с 0** (январь — 0, декабрь — 11).

```javascript
const now = new Date();

const year = now.getFullYear();       // Год (напр., 2023)
const month = now.getMonth();         // Месяц (0-11)
const day = now.getDate();            // День месяца (1-31)
const hours = now.getHours();         // Часы (0-23)
const minutes = now.getMinutes();     // Минуты (0-59)
const seconds = now.getSeconds();     // Секунды (0-59)
const milliseconds = now.getMilliseconds(); // Миллисекунды (0-999)

// День недели (0 - воскресенье, 1 - понедельник, ..., 6 - суббота)
const dayOfWeek = now.getDay(); 

console.log(`${day}.${month + 1}.${year} ${hours}:${minutes}`);
```

### 3. Форматирование в строку
Если вам нужно сразу получить человекопонятную строку, можно использовать метод `toLocaleString()` (или `toLocaleDateString`, `toLocaleTimeString`). Он автоматически учитывает локаль устройства или указанную вами.

```javascript
const now = new Date();

// Локальный формат (зависит от настроек браузера/ОС)
console.log(now.toLocaleString()); 

// Принудительный русский формат
console.log(now.toLocaleString('ru-RU', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
  hour: '2-digit',
  minute: '2-digit'
})); 
// Вывод: 27 октября 2023 г., 10:30
```

### 4. Получение времени в формате Unix (timestamp)
Если вам нужно количество миллисекунд, прошедших с 1 января 1970 года (часто используется для бэкенда или вычислений):

```javascript
// Способ 1
const timestamp = new Date().getTime();

// Способ 2 (более современный)
const timestampNow = Date.now();

console.log(timestampNow); // Например: 1698391845123
```

### Важное примечание о точности
Объект `new Date()` берет время с **компьютера или устройства пользователя**. Если часы на устройстве пользователя сбиты, дата также будет неверной. Для критически важных задач (например, финансовые транзакции или синхронизация игровых событий) время следует получать с доверенного сервера через API, а не полагаться только на клиентский JS.
